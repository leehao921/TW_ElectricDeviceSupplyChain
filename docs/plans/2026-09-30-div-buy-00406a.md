# 00406A 除息日半自動買入 (div_buy)

**日期:** 2026-09-30
**需求:** 每月 00406A (主動中信台灣收益, 月配) 除息日買入 1 張, 限價 = 除息參考價。
**用戶決策 (2026-09-30 AskUserQuestion):**
- 半自動: 除息日盤前推播, 用戶跑一行指令確認才送單 (保留 operator-armed 精神, 不做無人值守下單)
- 固定 1 張 (Common lot, 現股)
- 限價 = 除息參考價 (ROD, 當日未成交即失效, 不追價)

## 帳戶與憑證 (2026-09-30 實測)

- 期貨用 API key (nautilus `.env`) **看不到證券帳戶** → 用戶另建股票專用 key (2026-09-30 13:20)
- 股票 key 存 `~/.config/shioaji/stock.env` (0600, 不入 git): `SHIOAJI_STOCK_API_KEY` / `SHIOAJI_STOCK_SECRET_KEY`
- 登入後 `stock_account` 9A95…932 signed=True; CA 沿用 nautilus `.env` 的 `CA_CERT_PATH`/`CA_PASSWORD` (同身分證), `activate_ca` 回 True
- 此帳戶現有 00406A 2 張 @9.95 (與主持股券商 App 為不同帳戶)
- 注意: 同身分證 5 連線上限, daemon 已佔 4 → confirm 登入需 451 backoff, 下單完立即 logout

## 資料源

- 除息日: TWSE OpenAPI `exchangeReport/TWT48U_ALL` (除權除息預告表), `Date` 為民國 `1151005`, `CashDividend` 公布前為空字串
- 前一日收盤: `tmf_market_data.institutional_stock.close_price` (估算參考價, 僅供推播與 sanity check)
- 權威參考價: 下單當下 Shioaji `api.Contracts.Stocks[code].reference`

## 元件

`scripts/div_buy.py` 兩個子命令:

1. `check` — launchd `com.lulala.div-buy` Mon-Fri 08:20
   - 抓 TWT48U, 找 config 內標的的除息日
   - 除息日 = 今天 → 推 inbox topic=`div-buy` 🟢, 附確認指令 `div_buy.py confirm 00406A-20261005`
   - 除息日在未來 1–4 天 → 預告 (每個 token 只推一次)
   - 無事件靜默 (不推)
2. `confirm <token> [--dry-run]`
   - Guards (任一失敗即中止, 不登入): token 日期 = 今天、標的在 config、config.enabled、TWT48U 仍確認今天除息、未曾下過 (state 冪等)、時間在 08:30–13:25、張數 ≤ max_lots
   - 登入股票 key → activate CA → 取 `contract.reference`
   - Sanity: 參考價必須 < 前一日收盤 (除息必降);若配息已公布, |ref − (prev − div)| ≤ 1 tick。不過 → 中止 (合約檔可能尚未更新)
   - 下單: Buy / LMT @ref / ROD / Common / Cash, qty = lots
   - 寫 state (`data/div_buy_state.json`), 推 inbox 結果 (成功或失敗都推)

設定 `data/div_buy_config.json`: `{"enabled": true, "max_lots": 2, "items": [{"ticker": "00406A", "lots": 1}]}`
